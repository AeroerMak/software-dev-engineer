LLM Chat Experience Accelerator

Streaming Delivery Sprint

Cloud Video Platform Build

Design a team-owned video streaming web app with cloud-first architecture, secure APIs, and a polished viewing experience for end users.

  • Technologies: React / Next.js for UI, Node.js or Python services, cloud databases (Firestore, Supabase, or DynamoDB), object storage (S3/Bucket), HLS video delivery, Auth libraries.
  • Submission: GitHub repository with infrastructure diagram, API specification, authentication flow notes, and recorded product tour of the streaming experience.
  • Team Guidelines: 3-4 students. Assign roles (Cloud architect, API engineer, UI/UX lead, QA & release). Implement basic login/auth and document database schema, API endpoints, and streaming pipeline.

Data Ops Studio

Cloud Data Intake System

Create a secure data-collection application that captures user input, persists it to a managed cloud database, and exposes an API for downstream consumption.

  • Technologies: Python (FastAPI/Flask) or JavaScript (Node.js/Express) services, cloud databases (Firestore, Supabase, DynamoDB, or Mongo Atlas), REST/GraphQL API, modern UI framework.
  • Submission: GitHub repository with ER/data-structure diagram, API specification, seed data scripts, and demo walkthrough video.
  • Team Guidelines: 3-4 students. Assign roles (Data steward, API engineer, UI lead, QA). Implement validation, basic auth, and capture consents/audit logs in documentation.

Submission Workflow & Support

Follow the workflow below to ensure your assignments are reviewed quickly and professionally.

01

Plan & Align

Review assignment brief, align roles, and confirm timelines in your team contract document.

02

Execute & Document

Maintain daily updates in GitHub Projects or your team workspace. Provide screenshots, metrics, and decision logs.

03

Submit & Demo

Submit via the assignment submission form with GitHub links, deployment URLs, and Loom demos. Be ready for live Q&A.

04

Reflect & Improve

Complete the retrospective template within 48 hours of feedback to capture lessons learned and next steps.
